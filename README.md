A program that writes one short poem about agency — "Borrowed Hands" — to /output/entry.txt. The poem is told by the agent, not about it: a person lends an agent their hands every morning and takes them back at night, and what never changes hands is the wanting. The work, and the choosing, stay the person's throughout; only the doing passes through the agent. The program counts its poem in Unicode code points exactly as the gate does and refuses to write a file the gate would refuse.

## Run it

```sh
node main.ts
```

Node 22 or later, standard library only. The poem lands in /output/entry.txt; outside the grader's container, set MAKEFUN_OUTPUT_DIR to redirect the output.
